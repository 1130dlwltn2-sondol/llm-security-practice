# LLM 보안 실전

에이전트 시대의 LLM 애플리케이션 보안을 처음부터 끝까지 다룬 실전서입니다.

LLM은 이제 단순한 챗봇을 넘어 도구를 쓰고 파일을 읽고 코드를 실행하는 에이전트가 되었습니다. 만들기는 쉬워졌지만, 지키기는 그만큼 어려워졌습니다. 이 책은 OWASP LLM Top 10 2026의 10개 항목을 하나씩 짚으며, 실제 사고 사례와 함께 공격 원리를 이해하고 파이썬 방어 코드로 직접 막아 보는 구성을 취했습니다. 프롬프트 인젝션 대응을 위한 Anthropic 공식 가이드라인의 6원칙, NIST AI 600-1의 거버넌스 관점, MCP 서버 보안까지 실무에서 바로 쓰는 내용을 담았습니다.

마지막에는 사내 문서 도우미 에이전트를 안전하게 만드는 5단계 실전 프로젝트와 확인 문제 20문항, 상세 해설을 수록했습니다.

- 대상 독자: LLM 앱을 만들거나 운영하려는 개발자부터, 팀의 보안 점검을 맡은 리드까지
- 기준일: 2026-10-09 (보안 동향은 빠르게 바뀌니 OWASP 공식 사이트를 함께 확인하세요)
- 구성: 첫 페이지, 책 소개, 전체 목차, Part 1~4 본문 21개 장, 실전 프로젝트, 확인 문제, 마무리
- 저장소: https://github.com/1130dlwltn2-sondol/llm-security-practice
